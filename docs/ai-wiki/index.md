# index — vault 카탈로그

이 문서는 vault 전체의 **내용 지도**입니다. 폴더 목록이 아니라 **문서별 한 줄 요약 목록**입니다.
에이전트는 작업 시작 시 이 문서를 먼저 읽고, 위키 문서를 만들거나 상태를 바꾸면 여기에 반드시 반영합니다.

> 등재 규칙: `[[문서]] — 한 줄 요약` 형식. 요약 없는 링크는 등재하지 않습니다.

---

## 규약 문서 (Schema)

- [[AGENTS]] — 모든 에이전트가 따르는 정본 규약. 3계층 원칙, 5필터, 문서 포맷
- [[CLAUDE]] — Claude Code 진입점. 자연어 트리거 매핑과 도구 사용 규칙
- [[START_HERE]] — 사람용 온보딩. 이 vault를 처음 열었을 때 읽는 문서
- [[log]] — 시간순 작업 로그
