# CLAUDE.md — Claude Code 진입점

이 vault의 **규칙 정본은 `AGENTS.md`** 입니다. 아래를 반드시 먼저 읽으세요.

@AGENTS.md

> 위 `@` import가 동작하지 않는 환경이라면, 작업 전에 `AGENTS.md`를 직접 열어 읽으세요.
> 규칙은 그 문서에만 있습니다. 이 파일은 Claude Code 고유 동작만 정의합니다.

---

## 세션 시작 절차 (필수)

이 vault에서 어떤 작업 요청을 받든, 답을 만들기 **전에** 다음을 수행합니다.

1. `index.md`를 읽어 현재 카탈로그를 파악한다.
2. `log.md`의 마지막 10줄을 읽어 최근 작업 흐름을 파악한다.
3. 요청과 관련된 `AI-Sessions/wiki/` 문서를 찾아 읽는다. (`reference` 명령)
4. 관련 문서를 못 찾았으면 "위키에 관련 문서 없음"이라고 명시하고 진행한다. **없는 맥락을 지어내지 않는다.**

## 자연어 → 명령 매핑

| 사용자 발화 | 명령 |
|---|---|
| "옵시디언에 저장해줘", "위키에 남겨줘", "이번 작업 기록해줘" | `save` |
| "옵시디언 참조", "위키 확인하고", "이전 맥락 불러와", "지난번에 뭐 했지" | `reference` |

애매하면 실행 전에 어떤 명령으로 해석했는지 한 줄로 밝히고 진행합니다.

## 도구 사용 규칙

- 위키 검색은 `Grep`(내용) + `Glob`(파일명)을 먼저 씁니다. 파일을 통째로 읽기 전에 후보를 좁히세요.
- **`AI-Sessions/raw/` 아래에는 어떤 쓰기 도구도 사용하지 않습니다.** `Write`, `Edit`, `mv`, `rm` 모두 금지.
- 기존 문서 수정은 `Edit`(부분 치환)을 씁니다. `Write`로 통째 덮어쓰면 다른 세션이 추가한 내용이 사라집니다.
- `log.md`는 **append만** 합니다. 기존 줄을 건드리지 마세요.
- 문서를 새로 만들 때는 `templates/` 아래 해당 타입 템플릿을 복사해 채웁니다.

## 응답 스타일

- 한국어 해요체.
- 결론 먼저, 근거는 뒤에.
- 저장 여부를 물으면 5필터 중 **몇 번을 통과했는지 번호로** 답합니다.
- 불확실한 내용은 추측하지 말고 "확인 필요"로 표시합니다.
