# 애플 스타일 디자인 (튜너형 큰 숫자)

## Summary
팝업·영상 위 컨트롤·알림·아이콘을 **애플 기본 앱 디자인 언어**로 바꾼다. 화면 구성은 **튜너형**(아주 크고 얇은 키 숫자 하나 + 눈금 바늘). 이름 Tono는 유지. [[2026-11-01-앱-이름-Tono-및-미니멀-디자인]]의 디자인 부분을 대체.

## Context
1차 미니멀 디자인(인디고 단일 액센트)에 대해 오너: "여전히 좀 못생겼다", 불만은 **전체적인 느낌**. 방향 질문에서 "큰 숫자 하나(튜너형)" 선택 후 "애플에서 디자인한 앱 같은 느낌으로" 요청.

## 검토한 대안 (방향 질문 보기)
| 대안 | 채택 |
|---|---|
| 큰 숫자 하나 (튜너형) | **O** |
| 토스 스타일 카드 | X |
| 다이얼/노브 | X |
| (중간 시안) 검정+앰버 오디오 장비 톤 | X — 작업 중 "애플 느낌" 요청으로 전환 |

## 디자인 규칙 (공통 가이드)
- **색**: iOS 시스템 색 그대로. 틴트 systemOrange `#FF9500`(다크 `#FF9F0A`), 스위치 systemGreen `#34C759`(다크 `#30D158`). 배경 systemGroupedBackground `#F2F2F7`(다크 `#000`), 카드 `#FFF`(다크 `#1C1C1E`), 라벨 투명도(0.6/0.3), 구분선 0.5px 왼쪽 들여쓰기
- **타이포**: `-apple-system`/SF Pro. 키 숫자 84px weight 200, tabular-nums(시계 앱 느낌). 음수는 `−`(U+2212)
- **팝업**: 내비 바(왼쪽 설정 아이콘·가운데 제목+연결 상태·오른쪽 iOS 스위치) → 히어로 카드(큰 숫자, 25칸 눈금+주황 바늘 = 드래그 가능한 range, iOS 스테퍼 − | +, 틴트 캡슐 "원키") → 프리셋 회색 캡슐 → 그룹 리스트(iOS 슬라이더 속도/볼륨, 보컬 줄이기 스위치). 설정은 iOS 설정 앱식 화면 전환(‹ Tono)
- **영상 위 컨트롤**: macOS 제어 센터 재질 — `rgba(36,36,38,.62)` + `blur(30px) saturate(180%)`, 0.5px 테두리, 반경 18, 모듈 카드, 두꺼운 캡슐 슬라이더(흰색 채움), 원형 헤더 버튼
- **키 변경 알림**: 다이내믹 아일랜드식 검은 캡슐(상단 중앙, 스프링 애니메이션, 주황 ♯ 글리프)
- **아이콘**: 슈퍼타원 스퀘어클(n=5) + 오렌지 세로 그라데이션 `#FFB340→#FF8A00` + 상단 광택 + 흰 ♯(그림자). 16·32px는 광택·그림자 없는 굵은 획 버전
- **단축키 표시**: macOS에서는 ⌃⌥⇧⌘ 기호(`formatShortcutLabel`), 저장 값은 "Alt + K" 형식 유지
- 슬라이더 채움은 `--fill-pct` CSS 변수로 칠함(popup.js `paintSlider`, karaoke-ui.js `paintSlider`)
