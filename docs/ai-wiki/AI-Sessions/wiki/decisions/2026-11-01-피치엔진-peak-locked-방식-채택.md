# 피치 엔진 peak-locked 위상 보코더 채택

## Summary
AudioWorklet 피치 엔진을 bin별 위상 누산 방식에서 Laroche–Dolson peak-locked 영역 이동 방식으로 바꾼다.

## Context
기존 방식은 음정은 정확했지만 키 변경 시 3-24dB 음량 손실이 있었음 → [[피치-변경-시-음량이-3-24dB-줄어듦]].

## 검토한 대안
| 대안 | 장점 | 단점 | 채택 |
|---|---|---|---|
| bin별 위상 누산 + 분수 bin 분배 (기존) | 단순 | 로브 위상 관계 파괴 → 음량 손실 | X |
| 타임스트레치(PV) + 리샘플링 | 교과서적 고품질 | 실시간 스트리밍 리샘플러 추가, 지연·복잡도 증가 | X |
| peak-locked 영역 이동 + 피크별 위상 회전 | 로브 모양·음량 보존, 화음 정확, 기존 대비 ~3배 빠름 | 피크 위치 반올림(≤0.5 bin) 오차 | O |

## 선택 근거
오프라인 테스트 17종 통과(음정 ±5 cent, 레벨 ±1.5dB, C-E-G 화음, 지속음 떨림 <1.5dB). 헤드리스 Chromium e2e에서 +3키 523.26Hz/음량 차 0.13dB.
구현 포인트: 피크 = 로컬 최대(-100dB 플로어), 영역 경계 = 두 피크 사이 최소 bin, 회전 θ는 이전 프레임에서 해당 bin을 소유한 영역의 θ를 이어받음(피크가 1 bin 움직여도 연속).

## 되돌리는 조건
실제 곡에서 트랜지언트 번짐/금속성(phasiness)이 심하다는 청취 피드백이 있으면 타임스트레치+리샘플링 방식 재검토.
