# 앱 이름 Tono 및 미니멀 디자인

## Summary
앱 이름을 **Tono — 유튜브 노래방 키 조절**로 바꾸고, 아이콘·팝업·플레이어 오버레이를 "중립 회색 + 단일 액센트" 미니멀 디자인으로 통일한다.

## Context
사용자 피드백: 기존 디자인(네온 핑크·시안·보라 그라데이션, 글로우, 이모지 다수)이 촌스럽고 이름도 바꾸고 싶음. 이름과 스타일은 사용자가 "진행해"로 위임 → Claude가 기본값으로 결정.

## 검토한 대안
| 대안 | 장점 | 단점 | 채택 |
|---|---|---|---|
| 이름 유지 + 스킨만 교체 | 스토어 검색 연속성 | 사용자 요청 불충족 | X |
| 영문 단어 단독 (Tono) | 짧고 기억하기 쉬움 | 한국어 검색 키워드 상실 | X |
| **Tono + 한국어 부제** | 브랜드 + 검색어(노래방/키 조절) 유지 | 이름이 길어짐(스토어 75자 제한 내) | O |
| 아이콘: 마이크 | 노래방 연상 | 흔함, 16px에서 뭉개짐 | X |
| **아이콘: 음악 샤프(♯)** | "키/음정" 직관, 16px 가독 | 굵기 잘못 잡으면 해시태그(#)로 보임 | O |

## 선택 근거 · 디자인 규칙 (공통 가이드)
- **색**: 액센트 하나 — 라이트 `#4F5BD5`, 다크 `#8B94F5`. 나머지는 중립 회색. 키 올림/내림도 같은 액센트(부호로 구분).
- **팝업**: `prefers-color-scheme`로 라이트/다크 자동. 320px, 시스템 폰트(Pretendard/Apple SD Gothic Neo 우선), 반경 10px, 그림자·그라데이션 없음.
- **오버레이**: 영상 위라 항상 다크 반투명(blur 16px), 248px.
- **아이콘**: 둥근 사각형 + 흰색 ♯. 세로 획은 얇게, 가로 빔은 두껍고 기울게 (같은 굵기면 해시태그로 읽힘 — 1차 시안에서 실제로 발생). 16·32px는 `icons/icon-small.svg`(굵은 획), 48·128px는 `icons/icon.svg`. PNG는 Chrome 헤드리스로 렌더.
- **문구**: 이모지·영문 병기 제거. "보컬 컷(MR 모드)" → "보컬 줄이기", "리모콘" → "화면 컨트롤", OSD는 `−4 · 4키 내림`처럼 짧게. 음수는 하이픈 대신 `−`(U+2212).
- **중복 제거**: 팝업의 −1/+1 버튼 줄(◀▶와 중복) 삭제. 유튜브 컨트롤 바 버튼은 원키·ON일 때 배지를 숨겨 기본 버튼처럼 보이게.
