# 피치 변경 시 음량이 3-24dB 줄어듦

## 증상
키를 0이 아닌 값으로 바꾸면 반주가 원키보다 작게 들림. 오프라인 측정(330Hz 사인, `tests/pitch-worklet.test.mjs`):
-12키 -3.4dB, -5키 **-24.0dB**, -4키 -3.5dB, -1키 -4.5dB, +4키 -9.2dB, +5키 -7.3dB. 음정(cent) 자체는 정확했음.

## 환경
- `content/pitch-worklet.js` 1.1.x (STFT 2048/hop 512, 분수 bin 분배 방식)
- Chrome AudioWorklet, 48kHz

## 원인
bin마다 독립 위상 누산기(`sourcePhase[bin]`)를 0에서 시작해 누적함. Hann 창에서 한 사인파는 3~4개 bin(메인 로브)에 걸치고 인접 bin끼리 위상이 반대인데, 이 관계가 깨져서 역FFT 결과가 창 모양을 잃고 합성창·OLA에서 에너지가 상쇄됨. 하향 시프트에서 여러 source bin이 같은 target bin에 모이며 상쇄가 더 커짐(-5키 -24dB).

## 해결
Laroche–Dolson peak-locked 시프트로 교체: 피크를 찾고, 피크 주변 영역(로브)을 정수 bin만큼 통째로 이동, 영역 전체에 같은 위상 회전(프레임 간 누적)을 적용해 정확한 목표 주파수를 맞춤. 결과: 전 구간 ±1.5dB 이내, 브라우저 실측 +3키 -13.34dB vs 원음 -13.47dB. 상세는 [[2026-11-01-피치엔진-peak-locked-방식-채택]].

## 시도했지만 안 된 방법
- 테스트를 단일 사인 음정(cent)만 보면 이 버그가 안 보인다. 반드시 **레벨(dB)도 함께** 측정할 것.
- 화음 테스트에서 C-E-G를 -4/+3 시프트하면 이동한 음이 원래 다른 음과 겹쳐(E-4=C, E+3=G) "원음 잔존"으로 오탐 — 겹치지 않는 시프트(-5, +2) 사용.

## 재발 방지
워크릿 수정 시 `node --test tests/*.test.mjs` 필수 (음정 5 cent, 레벨 ±1.5dB, 화음, 지속음 떨림 1.5dB, 유휴 전환).
