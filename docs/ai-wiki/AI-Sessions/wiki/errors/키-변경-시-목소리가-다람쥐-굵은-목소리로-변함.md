# 키 변경 시 목소리가 다람쥐·굵은 목소리로 변함

## 증상
사용자 보고: "이거 쓰면 사람 목소리들이 이상하게 들린다". 사용자가 확인한 원인은 **음색 변화(포먼트 이동)** — 키를 올리면 다람쥐, 내리면 굵고 둔한 목소리.
측정 중 별개 결함도 발견: 가운데 보컬이 L−R(side)로 −18.5dB 새어 퍼지고 울리는 소리.

## 환경
- v1.2.0 `content/pitch-worklet.js` (peak-locked PV, 채널별 독립 처리, 포먼트 보정 없음)

## 원인
1. 포먼트: 하모닉과 함께 스펙트럼 윤곽(포먼트)까지 비율대로 이동 — 피치 시프트의 본질적 현상, 보정 없으면 항상 발생
2. 스테레오: L/R이 각자 피크·영역·회전을 계산 → 가운데 보컬이 양쪽에서 미세하게 다르게 처리됨

## 해결
[[2026-11-01-포먼트-유지-및-스테레오-링크]] (True Envelope 포먼트 보정 + 스테레오 링크)

## 시도했지만 안 된 방법 (재시도 금지)
- **일반 켑스트럼 스무딩 1회**: 피크·골을 평균내 포먼트가 뭉개짐. 리프터 1.1ms는 효과 없음, 2.5ms 이상은 400Hz 고음에서 하모닉을 윤곽으로 착각해 −17dB 붕괴
- **풀링 도메인에서 리프터를 ENVELOPE_POOL로 나눔**: 버그. 4배 풀링해도 켑스트럼 인덱스 n은 n/sampleRate초 (N·Δf = sampleRate 불변). 실제 리프터가 0.25ms가 됨
- **포먼트 보정을 전 대역에 적용**: −7키에서 'ㅅ' 같은 치찰음(5~8kHz)이 내려오며 원래 조용하던 대역 기준으로 −12dB 깎여 먹먹해짐 → 3~5kHz에서 페이드아웃
- **첫/마지막 하모닉 경계 칸 값으로 바깥 채우기**: 경계 칸은 피크 옆 비탈(−30dB)이라 혹이 남음 → 피크 실제 높이로 채움
- **단일 피크 위치 지표로 포먼트 테스트**: 좁은 포먼트+하모닉 샘플링 때문에 흔들림 → 하모닉 세기 vs 원래 윤곽의 RMS dB 오차(timbreError)로 측정
- **스펙트럼 무게중심으로 말소리 평가**: 기본음 에너지가 지배해 음정을 따라 움직임 → 500~3500Hz 1/3옥타브 LTAS 비교 사용
- 스테레오 테스트 반주 659Hz가 보컬 3배음(660Hz)과 겹쳐 오탐 → 587/740Hz 사용

## 재발 방지
`tests/pitch-worklet.test.mjs`의 timbre(110/220/300Hz), stereo link(<−40dB), sparse sound(±1.5dB) 테스트
