# START_HERE — 이 vault를 쓰는 법 (사람용)

이 폴더는 **여러 AI 에이전트가 같은 업무 맥락을 공유하는 업무 위키**입니다.
개인 메모장이 아니라, "지난번에 뭐 했더라"를 매번 다시 설명하지 않게 만드는 프로세스입니다.

## 하루 사용 흐름 (1단계)

```text
작업 시작 →  "옵시디언 참조하고 시작해줘"      (reference)
작업 종료 →  "이번 작업 옵시디언에 저장해줘"    (save)
```

Claude Code에서는 `/reference`, `/save` 슬래시 명령도 그대로 씁니다.

## 파일별 용도

| 파일 / 폴더 | 용도 | 누가 씀 |
|---|---|---|
| `AGENTS.md` | **규칙 정본.** 3계층 원칙, 5필터, 문서 포맷, 금지사항 | 사람이 승인, 에이전트는 요청 시에만 수정 |
| `CLAUDE.md` | Claude Code 진입점. `AGENTS.md`를 불러오고 자연어 트리거·도구 규칙만 추가 | 〃 |
| `index.md` | **vault 카탈로그.** 문서마다 한 줄 요약 | 에이전트 |
| `log.md` | 시간순 작업 로그. append만 함 | 에이전트 |
| `templates/` | 문서 타입별 뼈대 | 에이전트가 복사해 사용 |
| `AI-Sessions/raw/` | **불변 원본. 사람만 넣습니다.** 에이전트는 읽기만 | 사람 |
| `AI-Sessions/wiki/` | 가공된 지식. 에이전트가 유지보수 | 에이전트 |
| `AI-Sessions/conversations/` | 세션 인수인계 메모 | 에이전트 |

## 핵심 규칙 3개만 기억하면 됨

1. **원본은 `raw/`, 가공물은 `wiki/`.** 에이전트는 `raw/`를 절대 고치지 않습니다.
2. **폴더는 문서 종류(type), `domain` 필드는 업무 영역.** 영역별로 폴더를 만들지 않습니다.
3. **저장 5필터를 통과한 것만 저장.** 일회성 답변은 저장하지 않습니다.

## 저장 5필터

1. 향후 실무에 반복해서 재사용될 데이터인가?
2. 다른 에이전트나 동료가 프로젝트를 이어받기 위해 반드시 읽어야 하는가?
3. 의사결정의 근거와 결정권자를 나중에 추적할 필요가 있는가?
4. 실패한 방식이라 다시 시도하면 안 되는 리스크 정보인가?
5. 팀 전체가 맞추어야 하는 공통 규칙이나 디자인 가이드인가?

## Obsidian 설정 권장값

- `설정 → 파일 및 링크 → 새 노트 기본 위치`: 현재 폴더
- `설정 → 코어 플러그인 → 템플릿` 활성화 후 템플릿 폴더를 `templates` 로 지정
- 그래프 뷰에서 `AI-Sessions/wiki` 만 보면 지식 연결 상태가 한눈에 보입니다
