# 🎤 유튜브 노래방 키 조절기 (YouTube Karaoke Key Pitch Shifter)

> **유튜브 노래방(TJ, 금영 노래방 등) 및 음악 영상의 음정(키, Pitch)을 속도 변화 없이 반음 단위로 실시간 조절할 수 있는 크롬 확장 프로그램입니다.**

![아이콘](icons/icon128.png)

---

## ✨ 주요 기능

- 🎵 **실시간 반음 단위 키(Pitch) 조절**: 속도(BPM/Tempo)는 그대로 유지한 채 -12 ~ +12 반음(1 옥타브) 범위로 자유롭게 키를 올리거나 내릴 수 있습니다.
- 👨‍🎤 **원클릭 빠른 프리셋**:
  - **여키 변환 (👨→👩 -4키)**: 남자가 여자 노래 부를 때 최적화
  - **남키 변환 (👩→👨 +4키)**: 여자가 남자 노래 부를 때 최적화
  - **원키 리셋 (0 Key)**: 즉시 원곡 키로 복구 (Bypass 모드로 음질 손실 0%)
- ⏱️ **템포(재생 속도) 미세 조절**: 0.7x ~ 1.3x 범위로 반주 속도 조절 가능
- 🎙️ **보컬 컷 (가라오케 MR 추출 모드)**: 일반 원곡 뮤직비디오/음원에서 센터 보컬을 감쇄하여 노래방 MR처럼 만드는 기능
- 🔊 **MR 볼륨 부스터**: 유튜브 반주 소리가 작을 때 최대 200%까지 볼륨 증폭
- 🎛️ **유튜브 플레이어 일체형 오버레이 리모콘**:
  - 유튜브 전체화면에서도 완벽 동작하는 드래그 가능한 미니 리모콘
  - 최소화 / 접기 기능 지원
  - 유튜브 하단 컨트롤 바에 원클릭 바로가기 버튼 제공
  - 단축키 조작 시 화면 중앙 대형 OSD(On-Screen Display) 알림
- ⚡ **편리한 단축키 지원**: 노래 부르는 도중 키보드로 손쉽게 조절

## ⌨️ 단축키 안내

| 기능 | 기본 단축키 | 대체 단축키 |
| :--- | :--- | :--- |
| **반음 내리기 (♭ -1 Key)** | `[` | `Alt + ,` |
| **반음 올리기 (♯ +1 Key)** | `]` | `Alt + .` |
| **원키로 리셋 (0 Key)** | `\` | `Alt + /` |
| **오버레이 리모콘 켜기/끄기** | `Alt + M` | - |
| **보컬 컷 (MR 모드) 토글** | `Alt + V` | - |

*(유튜브 댓글창이나 검색창에 글을 작성 중일 때는 단축키가 작동하지 않도록 안전하게 보호됩니다.)*

## 🚀 크롬 브라우저에 설치하는 방법

1. 크롬 브라우저를 열고 주소창에 `chrome://extensions` 를 입력하여 확장 프로그램 관리 페이지로 이동합니다.
2. 우측 상단의 **[개발자 모드 (Developer mode)]** 스위치를 켭니다.
3. 좌측 상단에 나타나는 **[압축해제된 확장 프로그램을 로드합니다 (Load unpacked)]** 버튼을 클릭합니다.
4. 본 프로젝트 폴더(`wolfeel`)를 선택합니다.
5. 유튜브(https://www.youtube.com)에 접속하여 노래방 반주(예: `TJ 노래방`, `KY 노래방`)를 검색하고 재생하면 화면 우측 상단에 노래방 리모콘이 자동으로 표시됩니다!

## 💡 노래방 꿀팁

- **남자가 여자 노래를 부를 때**: `-4키` 또는 `-5키`를 내리면 가장 부르기 편한 음역대가 됩니다.
- **여자가 남자 노래를 부를 때**: `+4키` 또는 `+5키`를 올리면 자연스러운 고음역대로 소화할 수 있습니다.
- **MR이 없는 일반 곡**: `보컬 컷 (MR모드)` 스위치를 켜면 보컬이 제거되어 반주만 남으므로 어떤 노래든 노래방처럼 즐길 수 있습니다.
