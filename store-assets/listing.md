# Chrome 웹 스토어 등록 정보 (v1.3.0)

## 이름 (manifest와 동일, 자동 반영)
Tono — 유튜브 노래방 키 조절

## 요약 (manifest description, 자동 반영)
유튜브 노래방·음악 영상의 키(음정)를 속도 변화 없이 반음 단위로 조절합니다. 곡별 키 기억, 재생 속도, 보컬 줄이기를 지원합니다.

## 상세 설명 (대시보드에 붙여넣기)
유튜브 노래방(TJ, 금영 등)과 음악 영상의 키를 속도 변화 없이 반음 단위로 바꿔주는 확장 프로그램입니다.

■ 키 조절
- −12 ~ +12 반음, 재생 속도는 그대로
- 남→여 −4 / 여→남 +4 원클릭 프리셋
- 원키로 돌아가면 처리 없이 원음 그대로 재생
- 목소리 자연스럽게: 키를 바꿔도 다람쥐·굵은 목소리가 되지 않게 원래 음색 유지

■ 곡별 키 기억
- 한 번 맞춘 키를 기억했다가 같은 곡을 다시 열면 자동 적용 (설정에서 끌 수 있음)

■ 그 밖의 기능
- 재생 속도 0.7× ~ 1.3× (유튜브 속도 메뉴와 동기화)
- 볼륨 부스트 최대 200% (리미터로 깨짐 방지)
- 보컬 줄이기: 일반 음원에서 가운데 목소리를 줄여 반주처럼 사용
- 플레이어 위 화면 컨트롤 (전체화면 지원), 라이트/다크 모드 팝업

■ 단축키 (설정에서 변경 가능)
[ / ] 반음 내리기·올리기, Alt+0 원키, Alt+M 화면 컨트롤, Alt+V 보컬 줄이기, Alt+P 켜기/끄기

■ 1.3.0 업데이트
- 목소리 자연스럽게(포먼트 유지): 키를 바꿔도 원래 목소리 음색 유지
- 가운데 보컬이 퍼지고 울리던 현상 개선 (좌우 채널 일관 처리)

■ 1.2.0 업데이트
- 새 이름 Tono, 새 아이콘과 미니멀 디자인
- 키를 바꿀 때 소리가 작아지던 문제 해결
- 곡별 키 기억 추가
- macOS에서 Cmd+[ (뒤로 가기)가 키 내림으로 인식되던 문제 수정

개인정보: 어떤 데이터도 외부로 전송하지 않습니다. 설정과 곡별 키는 브라우저 로컬 저장소에만 저장됩니다.
